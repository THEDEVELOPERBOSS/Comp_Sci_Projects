Use Python 3.13 for this project. TensorFlow is not currently available for
Python 3.14.

From the repository root, create the project environment and install the
requirements:

```powershell
conda activate base
python -m venv --system-site-packages ".\Project 1\.venv"
& ".\Project 1\.venv\Scripts\python.exe" -m pip install -r ".\Project 1\requirements.txt"
```

Run the project with:

```powershell
& ".\Project 1\.venv\Scripts\python.exe" ".\Project 1\main.py"
```
